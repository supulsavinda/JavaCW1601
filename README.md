Malabe Tuk Spares Management System

About the Project
-This project was developed as part of my university coursework. It is a JavaFX application that helps manage a tuk-tuk spare parts inventory. The system allows users to view available parts, search for items, sort the inventory, and manage spare part records.

Main Features
-View all spare parts
-Search for parts by category, price, and keyword
-Sort parts by category using manual Bubble Sort
-Add new spare parts
-Update existing spare parts
-Delete spare parts
-Shopping cart with bulk and synergy discounts
-Checkout process with stock deduction
-View dealer directory
-Select 4 random dealers sorted by location
-View audit log of all operations
-Low stock monitoring

Technologies Used
Java 17
JavaFX
FXML
Maven
Scene Builder
JUnit 5

How to Run
Open the project in IntelliJ IDEA.
Wait for Maven to download the required libraries.
Run the MainApplication class.

Data Files
inventory_legacy.txt – Initial inventory data
dealers_legacy.txt – Dealer data
inventory_data.txt – Saved inventory data
audit_log.txt – Activity log
